# Ingler_Proyec_Inmobiliario
Plano arquitectónico 2D interactivo para un terreno de 7x17m. Creado con HTML5, CSS y SVG, permite visualizar dinámicamente mediante capas su zonificación, cotas, estructura y entorno. Destaca su diseño de concepto abierto, escalera en U con baño oculto y área de medidores. Ideal para presentar y explorar el proyecto web sin usar software CAD.
